# تيسير AI

**ذكاء يفهم تحديك.. ويصمم حلّك**

منصة ويب عربية تحلّل صورة ورقة كتابة الطفل بالذكاء الاصطناعي، وتقدّم تقريرًا وصفيًا بالأخطاء الإملائية وأنماطها ومؤشرات تستحق المتابعة، مع تمارين وألعاب قصيرة للتدريب. مشروع مقدَّم إلى مسابقة الابتكار في الذكاء الاصطناعي لخدمة الأشخاص ذوي الدسلكسيا.

- **النموذج التجريبي المباشر:** https://taysir-ai-phi.vercel.app
- **المستوى:** نموذج أولي وظيفي (MVP)

> **تنبيه جوهري:** تيسير AI أداة مساعدة للملاحظة الأولية فقط، وليست أداة تشخيص طبي أو تربوي. نتيجة التحليل مبنية على عينة كتابة واحدة وتحتاج دائمًا إلى مراجعة مختص.

## ما الذي يعمل فعليًا؟

| المكوّن | الحالة | ملاحظة |
|---|---|---|
| الماسح الذكي وتقرير التحليل | يعمل فعليًا | متصل بـ Google Gemini، مع نسخ وطباعة للتقرير |
| التمارين | يعمل فعليًا | بنك من 20 سؤالًا إملائيًا يُختار منه 5 عشوائيًا في كل جولة. المحتوى ثابت وغير مولَّد بالذكاء الاصطناعي، ويحتاج مراجعة معلم لغة عربية |
| الألعاب التعليمية (3) | يعمل فعليًا | محتوى ثابت |
| صفحة التواصل | يعمل فعليًا | ترسل رسالة إلى بريد الفريق عبر Resend |
| الدخول، وملفات الأطفال، ولوحة التحكم | **عرض تجريبي** | انظر القسم التالي |

### ما هو عرض تجريبي (وليس وظيفة حقيقية)

- **الدخول:** حساب تجريبي معلن على صفحة الدخول (`parent@taysir.ai` / `123456`). الجلسة محفوظة في المتصفح (`localStorage`) ويمكن تجاوزها، فالحماية للعرض فقط وليست حماية بيانات.
- **ملفات الأطفال:** ملفان تجريبيان ثابتان (أحمد وفاطمة) مدمجان في الكود لبيان شكل تقرير التقدم. لا إنشاء ولا حذف ولا حفظ.
- **لوحة التحكم:** بيانات نموذجية غير مرتبطة بالماسح.
- **الماسح لا يحفظ نتائج التحليل،** فلا توجد متابعة للتقدم عبر الزمن بعد.

## كيف يعمل الماسح؟

1. **المتصفح:** موافقة صريحة إجبارية (والزر معطّل بدونها)، ثم ضغط الصورة إلى 1600 بكسل بجودة 0.85.
2. **مسار API:** فحص المصدر (origin)، وحد للطلبات، وحد لحجم الصورة.
3. **Gemini:** قراءة الخط اليدوي وتصنيف الأخطاء ووصف الكتابة، بنموذج أساسي (`gemini-3.5-flash`) ثم احتياطي (`gemini-3.8-flash`). مهلة 15 ثانية للمحاولة و50 ثانية للإجمالي.
4. **الضبط والتحقق:** طبقتان فوق النموذج.
   - **تعليمات النظام (Prompt):** تفرض صياغة وصفية محايدة تتجنب لوم الطفل، وتمنع عدّ غياب التنوين أو التشكيل خطأ إملائيًا، وتعامل محتوى الصورة كبيانات لا كتعليمات.
   - **فلاتر في الكود:** تحذف الخطأ الذي يطابق فيه المكتوب الصواب، والخطأ الذي لا توجد كلمته في النص المقروء، وملاحظات الكتابة التي بلا مستوى صالح (بدل اختراع مستوى). وعدد الكلمات يُحسب في الكود من النص، لا من النموذج.
5. **التقرير:** النص كما قرأه الذكاء الاصطناعي بجانب جدول الأخطاء ليتحقق المستخدم بنفسه، وأرقام موصوفة بأنها «تقدير أولي»، ومؤشرات وتوصيات، وتنبيه أنه ليس تشخيصًا.

إن كانت الورقة فارغة أو لا تحتوي كتابة يدوية، تظهر رسالة مفهومة بدل تقرير مختلق.

## الخصوصية والقيود المعلنة

- تُرسل الصورة إلى Google Gemini للتحليل ولا تُحفظ على خوادم المشروع ولا تُكتب في سجلاتها.
- المفتاح على **الحصة المجانية** من Google. وفق شروط الخدمة المجانية قد يُستخدم المحتوى لتحسين خدماتها وقد يطّلع عليه مراجعون بشريون. **لذلك لا تُرفع صور أطفال حقيقيين في هذه النسخة،** والاختبار يكون بأوراق تجريبية بلا اسم أو بيانات تعريفية.
- قد تظهر رسالة «ضغط عالٍ» مؤقتًا في أوقات الازدحام (خطأ 503 من Google). أعد المحاولة بعد دقيقة.
- الحد من الإساءة مبدئي: عدّاد في ذاكرة الخادم (10 طلبات كل 10 دقائق).
- **الدقة لم تُقَس على خط أطفال حقيقي.** اختُبر الماسح على عينات صغيرة مطبوعة بخط حاسوب واضح وبأخطاء معروفة سلفًا، وهذا يثبت عمل الرصد والتصنيف ولا يقيس الدقة. لا تُذكر نسبة دقة.

## التقنيات

Next.js 16 · React · TypeScript · Tailwind CSS · Google Gemini API · Resend · Vercel · GitHub

واجهة عربية كاملة (RTL)، ووضعان فاتح وداكن، وزر إمكانية وصول، ودعم لقارئات الشاشة.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # ثم عبّئ القيم
npm run dev
```

افتح http://localhost:3000

### متغيرات البيئة

| الاسم | الاستعمال |
|---|---|
| `GEMINI_API_KEY` | تحليل الصور (سري) |
| `RESEND_API_KEY` | إرسال بريد صفحة التواصل (سري) |
| `CONTACT_TO_EMAIL` | البريد الذي تصله الرسائل |
| `NEXT_PUBLIC_DEMO_MODE` | `true` لإظهار الحساب التجريبي في صفحة الدخول |

لا تضع أي مفتاح حقيقي في المستودع. وبما أن متغيرات `NEXT_PUBLIC_` تُدمج وقت البناء، فعدّلها ثم أعد النشر (Redeploy).

## خارطة الطريق (غير منفَّذة بعد)

- توليد تمارين بالذكاء الاصطناعي من أخطاء الطفل الفعلية، ومراجعة معلمين لبنك الأسئلة.
- مصادقة وجلسات من الخادم وقاعدة بيانات تحفظ نتائج التحليل وملفات الأطفال (إنشاء وحذف)، وتربط كل ولي أمر بحسابه.
- دراسة بالتعاون مع مختصين وبموافقة الأهل لقياس دقة قراءة الخط اليدوي وتصنيف الأخطاء.
- سياسة خصوصية وموافقة ولي الأمر، والالتزام بأنظمة حماية المستخدمين دون 18 عامًا، والانتقال إلى خدمة مدفوعة لا تستخدم المحتوى لتحسين منتجات مزوّدها.
- تحليل صوتي للقراءة الجهرية، وتطبيق جوال.
